# Root Cause Analysis

The programming flaw category that led to the state observed immediate point of failure is what we will call the Root Cause. The Root Cause may be in a different location than the immediate point of failure, as the IPoF just demonstrates that the problem exists, but the Root Cause may have been caused elsewhere.
